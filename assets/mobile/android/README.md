# Android Store Assets

Keep Google Play-only assets here. These files are not copied into `core/frontend/public/` unless they are also needed by the website.

Recommended files:

- `icon-512.png`
- `feature-graphic.png`
- `screenshots/phone-01.png`
- `screenshots/phone-02.png`
- `screenshots/phone-03.png`

Do not store Play Console credentials, keystores, or signing passwords in this directory.
