## ✅ Проверенные скрипты

### 1. Назначение администратора

**Скрипт:** `core/backend/src/scripts/production/make-admin.ts`  
**Команда:** `npm run make-admin:prod`  
**Статус:** ✅ **Доступен на проде**

- ✅ Нет проверки окружения (работает в любом окружении)
- ✅ Поддерживает поиск по email: `--email user@example.com`
- ✅ Поддерживает поиск по телефону: `--phone +373XXXXXXXXX`
- ✅ Поддерживает обновление пароля: `--update-password --password newpass`

**Примеры использования:**
```bash
# По email
npm run make-admin:prod -- --email user@example.com

# По телефону
npm run make-admin:prod -- --phone +373XXXXXXXXX

# С обновлением пароля
npm run make-admin:prod -- --email user@example.com --update-password --password newpass123
```

### 2. Удаление роли администратора

**Скрипт:** `core/backend/src/scripts/production/remove-admin.ts`  
**Команда:** `npm run remove-admin:prod`  
**Статус:** ✅ **Доступен на проде**

### 3. Очистка данных (объявления и пользователи)

**Команда:** `npm run clear-listings-and-users:prod`  
**Статус:** ✅ **Доступен на проде** (создан)

- ✅ Нет проверки окружения (работает в любом окружении)
- ✅ Удаляет все объявления, пользователей и связанные данные
- ⚠️ **ВНИМАНИЕ:** Удаляет ВСЕ данные из базы!

**Что удаляется:**
- История промоций
- Просмотры объявлений

- Сохраненные фильтры

- Коды верификации телефонов
- Пользователи

**Пример использования:**
```bash
npm run clear-listings-and-users:prod
```

### ⚠️ Важные замечания:

1. **Очистка данных** - Выполняйте только после полного деплоя и проверки работоспособности
2. **Генерация данных** - Скрипты генерации (`seed.ts`) НЕ нужны на проде - данные создаются реальными пользователями
3. **Проверка окружения** - Все production скрипты либо не имеют проверки окружения, либо разрешают работу в production

## 🔍 Проверка перед использованием

Перед запуском скриптов на проде убедитесь:

- [ ] Переменные окружения настроены (`DB_HOST`, `DB_PORT`, `DB_USERNAME`, `DB_PASSWORD`, `DB_NAME`)
- [ ] База данных доступна
- [ ] Сделана резервная копия базы данных (для операций удаления)
- [ ] Понимаете последствия выполнения скрипта
